# HOI4 AI Operator architecture

## 2026-10-07 Time Ownership / Safe Stop / Modal Fail-Closed

Phase 5 中，Agent 决策与停机责任分离。AgentAdapter 只产生有限目录中的 semantic proposal；OperatorAPI 执行、验证并保存私有 GUI proof。GameTimeController 在可能恢复时间的输入之前取得 ownership；NativeClockGUI 负责确定性 GUI 暂停读回；NativeRuntimeHost 在退出时独立停机。Agent 错误、circuit breaker、bootstrap 或 cleanup 异常不能解除停止责任。

ownership 状态机为 UNKNOWN → PAUSED_CONFIRMED → RUNNING_OWNED → STOPPING → PAUSED_CONFIRMED；失败进入 STOP_FAILED_OWNED，仍 owned=true。只有确定性 GUI 暂停证据允许释放。每个 acquisition 只有一次正常 Space pause 与最多一次已校准 stop-only route；后续 ensure 调用只有被动确认，禁止无限重发。

NativeModalDetector 由 clock、UIState 和 NativeMapState 共享，避免同一未知叠层被地图层误报 MAP_READY。其已校准 menu/news/focus/research 和 centered rectangular candidates 只提供部分覆盖；UNKNOWN_MODAL / OVERLAY_STACK 均 fail-closed，无泛化 Escape、自动事件决策或 LLM/OCR reader。已有模板/几何/生产阈值、目标范围和 camera profile 不变。

正常 stop 失败的触发帧在恢复之前落盘，含 full RGB、clock/modal/menu ROI、UTC、telemetry、ownership、HWND/PID、foreground。捕获或写盘失败分别报告，不能用旧帧或 clean shutdown 隐藏故障。尚 owned 的退出必须 unsafe_stop_failed / game_pause UNKNOWN / operator intervention required。

Time Safety A/B 实机已验证、失败分支 C 仅离线：[验收记录](artifacts/phase5/time-safety-20261007/TIME_SAFETY_GATE.md)。它们不代表真实模型或国家自治验收。后续能力与验收路线见 [COUNTRY_AUTONOMY_PLAN.md](COUNTRY_AUTONOMY_PLAN.md)，保持五阶段结构，本轮不扩展 Air/Navy/任意省份操作。

新Construction single已实机confirmed；随后新30天在World News modal下停机失败，ownership仍保留，报告unsafe_stop_failed而非clean。当前安全路径覆盖有限、需要人工暂停；真实Codex尚未验收。详细数据见 [Phase5报告](PHASE5_AGENT_RUNTIME.md)。

## 前一轮checkpoint（保留历史，工具修复之前）

Agent → adapter → semantic Observation / Action / Result → MCP or Python API → domain service → deterministic GUI executor → InputBackend → HOI4.

`OperatorAPI.get_game_state(detail)`, `get_action_catalog()` and `execute(action, arguments)` expose semantic observations, current targets and results. Coordinates, templates, HWND, PID and backend objects are private configuration. `executor/backend.py` defines the replaceable input boundary. Phase 5 adds `windows_native.py` and `native_win32.py`: independently guarded GDI capture and public SendInput, without an OpenAI bridge. Native is the default when an existing GUI window is explicitly attached. `--backend computer-use` selects the optional `worker.py` bridge; `scripts/computer_use_pump.js` alone imports `@oai/sky`. Historical validation clients select that backend explicitly. Domain services do not import a vendor API. AgentRuntime, ScriptedAgent and the semantic CodexAdapter boundary are offline tested; actual native runtime and Codex provider gates remain pending.

For the optional Computer Use `--military` runtime, `executor/right_drag.py` wraps the same worker in `NativeRightDragBackend`. Only `right_drag(start, end)` uses public Windows SendInput; capture, clicks, keys and scrolling still delegate to Computer Use. The wrapper shares the existing action guard and transaction lock, requires an exact calibrated capture profile and matching Win32 client dimensions, checks before each input, issues at most one right-down, and releases in finally and on independently observed F12/focus/deadline/watchdog failures. Release failure is surfaced; ownership remains set for cleanup to retry. There is no activation, launch, general held-button API or Agent-facing coordinate interface. The 26 native safety tests remain offline; two independent official SDK offensive actions now prove normal live submission and release.

Existing Research / Focus / factory-count proof remains in its historical reports. New actions use `contracts.py` and `executor/pipeline.py`: fresh telemetry → guarded navigation → identity verification → at most one submission → exact readback → repeated confirmation. Legacy actions retain their proven transaction paths pending gradual migration; their result format is not yet fully unified.

Production extends existing session-local snapshots with version, TTL and identity signature. Construction, advisor and trade observations use the same session-local identity principle: 120-second TTL, changed-identity/version rejection, explicit GUI source and `stable_game_identity=false`. Mutations invalidate uncertain snapshots and never automatically resubmit. Per-line telemetry, complete construction progress and complete trade telemetry remain UNKNOWN; GUI evidence is separately identified.

New domain boundaries are `actions/production_lines.py`, `construction.py`, `politics.py`, `trade.py` and corresponding `executor/*_service.py` / `*_ui.py`. Catalogs provide semantic targets; `non_military_layout.py` owns private fixed-profile layout. The shared pipeline provides precheck, navigation, target verification, one submission, readback, confirmation and cleanup. Cleanup failure cannot retain the action lock or erase already established confirmation.

The Python facade accepts, for example, `operator.execute("build", {"state_id": 64, "building_type": "military_factory"})`. The Agent cannot configure or pass HWND, coordinates, templates or backend objects through action arguments. MCP v0.9.0 exposes 52 tools including the new observation/catalog interfaces; the operator explicitly configures the private `--non-military` or `--military` runtime at startup. Registration does not imply native live verification or Runtime availability. Unattached GUI tools reject. CodexAdapter is tested with fake providers; actual Codex isolation and live acceptance remain pending. Other vendors are future integrations.

The optional Computer Use backend requires an authorized pump; the native backend does not. Backend readiness is checked before live client actions; this does not extend action, bridge or watchdog deadlines. Focus loss, F12, HWND/PID/process checks and guarded Esc recovery remain in force. The executor never automatically refocuses. Native input additionally checks exact client/DPI geometry, modifiers/held inputs and the target window at each pointer destination. Finally and an independent monitor release owned inputs; failed release retains ownership and prevents another transaction. Mod edits, console, effects and direct save edits are prohibited.

The original calibrated profile remains HOI4 1.19.3, GER 1936 start, base Chinese, Telemetry Mod only, 2560×1080, scale 1.0; Phase 3 legal preparation naturally advanced into 1937. Catalogs deliberately reject uncalibrated targets. Limited Phase 3 remains OFFLINE TESTED / LIVE VERIFIED; its precise evidence is in [the Phase 3 report](PHASE3_NON_MILITARY_EXECUTOR.md).
